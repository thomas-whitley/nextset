# Competitor UX Teardown: Gym Set-Logging Apps

Research date: 2026-09-18. Scope: Hevy, Strong, Boostcamp, JEFIT, Liftin'. A sixth app (Alpha Progression) was considered — it is ranked #1 in [Alpha Progression's own "Best Gym Apps" blog post](https://alphaprogression.com/en/blog/best-gym-apps) and appears in several aggregator round-ups, but did **not** show up repeatedly across *independent* sources specifically for logging UX (e.g. [Garage Gym Reviews' "Expert-Tested" roundup](https://www.garagegymreviews.com/best-weightlifting-app) doesn't mention it at all, and covers Boostcamp/Fitbod/Caliber instead). Per the brief's bar ("comes up repeatedly... otherwise skip it"), it was **not added** as a full teardown; a few of its citable facts are used only in Divergent Choices for contrast.

Sourcing tiers used below: **Official** = vendor site/help-centre/App Store/Play listing/official blog (treated as fact, cited inline). **Review/Reddit** = third-party review sites or Reddit, explicitly marked "(review)" or "(user opinion)" — used only to fill gaps official sources don't cover, per the brief. Anything neither sourced nor safely inferable is marked **unverified** or **not found in sources**.

## Hevy

1. **Onboarding**: Free download, no upfront paywall; account setup takes a short questionnaire before first use ([Hevy App Store listing](https://apps.apple.com/us/app/hevy-workout-tracker-gym-log/id1458862350); signup portal at [hevy.com/signup](https://hevy.com/signup)). Exact tap-count to first logged set: **unverified** (review claim of "under 90 seconds" appeared in a repackaged blog summary, not an official Hevy source, so not cited as fact).
2. **Navigation**: Tab-based structure — Workout, a Discovery/social feed, and Profile (routines, calendar, statistics) — per [Hevy's own tutorial walkthrough](https://www.hevyapp.com/hevy-tutorial/). Progress/statistics and Calendar both live under Profile, not their own tabs ([Hevy Help Centre, calendar/streak article](https://help.hevyapp.com/hc/en-us/articles/35380117933207-Track-Your-Workout-Consistency-with-the-Calendar-and-Streak-Features)).
3. **Program/routine setup**: Users build reusable "routines" or start an empty workout; a routine library exists for various training styles/equipment ([Exercise Programming Options feature page](https://www.hevyapp.com/features/exercise-programming-options/); [tutorial](https://www.hevyapp.com/hevy-tutorial/)). Exercise library has 400+ entries with free videos, plus custom exercise creation ([Feature List](https://www.hevyapp.com/features/)). Supersets are supported as a set-type grouping ([tutorial](https://www.hevyapp.com/hevy-tutorial/)). Whether mid-workout routine edits persist back to the saved template: **not found in sources**.
4. **Active workout / logging**: Sets can be tagged Warmup, Normal, Drop, Failure, or grouped as Supersets ([App Store listing](https://apps.apple.com/us/app/hevy-workout-tracker-gym-log/id1458862350)). Previous performance for that exercise is shown "on the left" of the working set ([Hevy Help Centre feature guide, via search excerpt](https://help.hevyapp.com/hc/en-us/articles/33106320824727-Everything-You-Need-to-Know-About-the-Hevy-App-2025-Features-Guide)). Marking a set complete (checkbox) auto-starts the rest timer ([Rest Timer feature page](https://www.hevyapp.com/features/workout-rest-timer/)). Plate calculator and warm-up calculator exist as togglable "Workout Settings" ([Workout Settings Preferences article](https://help.hevyapp.com/hc/en-us/articles/33882110558743-Workout-Settings-Preferences-Timer-Warm-up-calculator-Plate-Calculator-Smart-Superset-Scrolling)). Notes are supported per exercise ([tutorial](https://www.hevyapp.com/hevy-tutorial/)). Reorder/replace exercise mid-workout: **not found in sources**.
5. **Rest timer**: Automatic on set completion; adjustable 5 seconds–5 minutes, ±15-second increments, skippable from a widget, with per-exercise custom durations ([Rest Timer & Default Rest Timer article](https://help.hevyapp.com/hc/en-us/articles/35385404949143-Rest-Timer-Default-Rest-Timer-How-to-Add-Adjust-Volume-and-Sound)). Surfaces via iOS/Android Live Activity / Dynamic Island and lock screen so the phone doesn't need to be unlocked ([Live Activity feature page](https://www.hevyapp.com/features/live-activity/); [How to Use Hevy's Live Activity article](https://help.hevyapp.com/hc/en-us/articles/35649846517399-How-to-Use-Hevy-s-Live-Activity-on-iOS-and-Android)). Timer can be turned off entirely, e.g. for supersets ([App Store listing](https://apps.apple.com/us/app/hevy-workout-tracker-gym-log/id1458862350)).
6. **Finish workout**: PR is flagged in real time the moment a set is marked complete, and appears again on the post-workout summary ([Exercise Performance feature page](https://www.hevyapp.com/features/exercise-performance/)). Discard flow and in-progress persistence on app kill: **not found in sources**.
7. **History & progress**: Calendar view under Profile highlights logged days in blue, scrollable back to first use, tapping a day opens that workout ([Calendar/Streak article](https://help.hevyapp.com/hc/en-us/articles/35380117933207-Track-Your-Workout-Consistency-with-the-Calendar-and-Streak-Features)). Per-exercise full-screen graphs, 1RM, best-set/session volume ([Exercise Performance page](https://www.hevyapp.com/features/exercise-performance/)). Monthly report: workouts completed, time trained, total sets, volume, muscle-volume distribution, PR list ([Monthly Report feature page](https://www.hevyapp.com/features/monthly-report/)). Body-composition tracking exists ([Gym Progress feature page](https://www.hevyapp.com/features/gym-progress/)).
8. **Delighters/complaints**: Rated 4.9/5 across 590,000+ combined App Store/Play ratings per Hevy's own site ([Feature List](https://www.hevyapp.com/features/)) — official source, so read as marketing, not independent sentiment. Independent Reddit-sourced complaints specific to Hevy: **not found in sources** (search did not surface a citable thread).

## Strong

1. **Onboarding**: An account is required before regular use — "all users will be prompted to sign up for an account before using Strong," via email, Google, Facebook, or Sign in with Apple ([Why do I need a Strong account?](https://help.strongapp.io/article/143-strong-account); [Sign in with Apple article](https://help.strongapp.io/article/215-sign-in-with-apple); [Google Play listing](https://play.google.com/store/apps/details?id=io.strongapp.strong&hl=en)). Reason given: cloud access across devices and sharing workouts/templates ([account article](https://help.strongapp.io/article/143-strong-account)).
2. **Navigation**: Help Centre categorizes the app into Getting Started, Recording Workouts, Workout Templates, Exercises, History/Metrics, Apple Watch, Integrations, Accounts ([Strong Help Centre](https://help.strongapp.io/)), implying a template/history/metrics tab structure; exact tab bar icons/labels: **not found in sources**.
3. **Program setup**: Start from an "Empty Workout" or a Template/Routine ([How do I perform a workout with Strong?](https://help.strongapp.io/article/229-my-first-workout)). Free tier caps custom routines at 3; PRO unlocks unlimited ([Strong App Store listing](https://apps.apple.com/us/app/strong-workout-tracker-gym-log/id464254577)). Supersets/circuits: tap the "..." menu on an exercise → Create Superset → select exercises to group; 3+ grouped exercises are called a Circuit ([About Supersets/Circuits](https://help.strongapp.io/article/98-supersets-and-circuits)). Editing a routine mid-workout: if the workout came from a Template and was changed, Strong prompts to either "Update Template" (overwrite) or "Update Values Only" (merge weights/reps) or leave the template unchanged ([Save a Workout as a Template article](https://help.strongapp.io/article/177-update-template)) — one of the more explicit "does it persist back?" answers found in any app's official docs.
4. **Active workout/logging**: Enter weight and reps, complete via checkbox ([My First Workout article](https://help.strongapp.io/article/229-my-first-workout)). Previous-performance auto-fill is described only in secondary sources (review): "you see the weight and reps from your previous session... automatically" (review, [RepReturn Strong review](https://repreturn.com/strong-app-review/)) — not confirmed in Strong's own help docs. Add-set via "Add Set" button; notes supported at the workout level; exercises reorder by drag-and-drop on the exercise name ([My First Workout article](https://help.strongapp.io/article/229-my-first-workout)). Plate calculator and warm-up calculator are listed features ([App Store listing](https://apps.apple.com/us/app/strong-workout-tracker-gym-log/id464254577)). Set tagging (warm-up, failure, drop) exists ([App Store listing](https://apps.apple.com/us/app/strong-workout-tracker-gym-log/id464254577)). Tap-count to log a set ("three taps") is a review claim only, not official ([RepReturn](https://repreturn.com/strong-app-review/); [The Nerdy Student review](https://www.thenerdystudent.com/2021/08/strong-review/)) — flagged as **review, not verified by Strong**.
5. **Rest timer**: Auto-countdown after a set is completed, with notifications; supports iOS Live Activity/Dynamic Island ([App Store listing](https://apps.apple.com/us/app/strong-workout-tracker-gym-log/id464254577)). Default duration and adjustment controls: **not found in official sources searched** ([About Rest Timer](https://help.strongapp.io/article/231-rest-timer) title found but content not retrieved).
6. **Finish workout**: Tap "Finish" — doesn't require every planned exercise/set to be done first. From an Empty Workout, finishing prompts "Save as New Template"; from a Template with changes, prompts Update Template / Update Values Only / Keep Original ([Update Template article](https://help.strongapp.io/article/177-update-template)). Discard flow and behaviour on app kill mid-workout: **not found in sources** — a dedicated "Lost Data" troubleshooting article exists ([Lost Data article](https://help.strongapp.io/article/217-lost-data)) implying data-loss is a known enough support topic to warrant its own page, but its resolution content wasn't retrievable here.
7. **History & progress**: History/Metrics is its own Help Centre category ([Strong Help Centre](https://help.strongapp.io/)); users can reset workout history ([Can I reset my workout history?](https://help.strongapp.io/article/250-can-i-reset-my-workout-history)). 1RM and total-weight-lifted analytics, volume/1RM graphs, body-measurement tracking with Apple Health integration, CSV export ([App Store listing](https://apps.apple.com/us/app/strong-workout-tracker-gym-log/id464254577)). Calendar vs. list for history: **not found in sources**.
8. **Delighters/complaints**: Independently and repeatedly cited as the minimalist/fast logger: Garage Gym Reviews-style round-ups summarized elsewhere describe it as "the best pure logging UX" (review, [search-aggregated round-up](https://www.jefit.com/blog/best-strength-training-apps-for-2026-7-options-tested-by-lifters)); Reddit sentiment (user opinion, not independently re-verified here) favors Strong/FitNotes for lifters who "minimize tap time and record PRs clearly."

## Boostcamp

1. **Onboarding**: A short in-app questionnaire drives an AI Coach that generates a multi-week plan from goals/schedule/equipment ([Boostcamp App Store listing](https://apps.apple.com/us/app/boostcamp-workout-programs/id1529354455)). Whether signup/account is mandatory before the first logged set: **not found in sources**.
2. **Navigation**: Tabs for Today's workout, Program library, History, and Analytics ([App Store listing](https://apps.apple.com/us/app/boostcamp-workout-programs/id1529354455)). Users pick their next routine day and start ("set it and forget it") — start-workout lives on the Today tab.
3. **Program/routine setup**: 11,000+ community programs plus 130+ coach-designed templates (Alberto Nuñez, Eric Helms, Geoffrey Schofield, Cody Lefever, Jim Wendler, etc.), filterable by level/goal/days-per-week ([Boostcamp Features page](https://www.boostcamp.app/features); [Free Workout App page](https://www.boostcamp.app/free-workout-app)). Popular templates include nSuns, 5/3/1, GZCLP, Reddit PPL, PHUL, PHAT ([Boostcamp vs. Hevy comparison page](https://www.boostcamp.app/vs/hevy)). Custom Program Builder supports multi-week mesocycles, supersets, drop sets, warm-up templates, training-max waves, custom exercises, and forking any existing program to tweak ([Workout Program Creator page](https://www.boostcamp.app/custom-program)); free tier has no cap on custom programs ([Features page](https://www.boostcamp.app/features)). Mid-workout exercise swaps "carry your weights to substitutes" ([Features page](https://www.boostcamp.app/features)) — i.e. a replace-exercise flow that preserves logged data, but whether the swap writes back to the saved template: **not found in sources**.
4. **Active workout/logging**: RPE and RIR fields on every set; e1RM calculated per top set ([Features page](https://www.boostcamp.app/features); [Workout Tracker page](https://www.boostcamp.app/workout-tracker)). Plate calculator "tells you exactly which plates to load" ([Features page](https://www.boostcamp.app/features)). Supersets, drop sets, customizable warm-up templates all supported ([Features page](https://www.boostcamp.app/features)). Previous-performance display, checkbox layout, and notes: **not found in sources**.
5. **Rest timer**: Built-in rest timer; on iOS, Live Activity puts the current set, rest timer, and next lift on the Lock Screen and in the Dynamic Island without unlocking the phone ([Boostcamp vs. StrongLifts comparison page](https://www.boostcamp.app/vs/stronglifts)). Per-exercise custom duration and skip/adjust controls: **not found in sources**.
6. **Finish workout**: Personal records "flag in-session" during the workout ([App Store listing](https://apps.apple.com/us/app/boostcamp-workout-programs/id1529354455)). A summary sheet with volume/duration, and a discard flow: **not found in sources**.
7. **History & progress**: Weekly "Sunday report" and year-end "Wrapped" summaries; monthly history view ([App Store listing](https://apps.apple.com/us/app/boostcamp-workout-programs/id1529354455)). PR types tracked automatically: max weight per rep range, max session volume, max reps at a given weight, lifetime bests, e1RM curve ([Workout Tracker page](https://www.boostcamp.app/workout-tracker)). Pro tier adds a 0–100 "Strength Score" and per-muscle volume heatmaps ([App Store listing](https://apps.apple.com/us/app/boostcamp-workout-programs/id1529354455)). Calendar vs. list for history and body measurements: **not found in sources**.
8. **Delighters/complaints**: 4.8/5 across 9,100+ App Store ratings per the public App Store listing. Praise (review/user opinion): "super easy to use," described as bringing Reddit's popular spreadsheet programs (5/3/1, PPL, etc.) into a working app ([aggregated in search results, unofficial]). Complaint (user opinion): some interface updates were described as confusing and there is no live chat/phone support, only email ([support@boostcamp.app](https://www.boostcamp.app/) contact) — sourced from aggregated review summaries, not a single citable primary URL, so treated as **review, not independently verified here**.

## JEFIT

1. **Onboarding**: A "reimagined onboarding" with entrance animations and haptics; new users get a complimentary 7-day trial of the Adaptive Plan before choosing a tier ([JEFIT App Store listing](https://apps.apple.com/us/app/jefit-workout-plan-gym-tracker/id449810000)). Exact tap-count and whether signup is mandatory before first set: **not found in sources**.
2. **Navigation**: Tabs include Discover, Workout, and Progress ([App Store listing](https://apps.apple.com/us/app/jefit-workout-plan-gym-tracker/id449810000); [JEFIT support: progress graphs](https://support.jefit.com/hc/en-us/articles/203688010-How-Do-I-View-My-Progress-Graphs-)). History (workout logs, progress photos, notes, body composition) lives under its own History tab with a color-coded calendar ([JEFIT support: exercise logs](https://support.jefit.com/hc/en-us/articles/202340464-Where-Can-I-See-The-Complete-Logs-For-A-Particular-Exercise-)). Recent redesign uses "Liquid Glass" styling on iOS 18+ ([App Store listing](https://apps.apple.com/us/app/jefit-workout-plan-gym-tracker/id449810000)).
3. **Program/routine setup**: 1,400+ exercises with HD video ([App Store listing](https://apps.apple.com/us/app/jefit-workout-plan-gym-tracker/id449810000)). Pre-built bodybuilding programs plus custom routines; JEFIT Elite adds an "Elite Routine Library" of science-backed templates ([App Store listing](https://apps.apple.com/us/app/jefit-workout-plan-gym-tracker/id449810000)). Supersets are configured via the three-dot menu in the top-right of the logging screen ([JEFIT: Upcoming Enhancements blog post](https://www.jefit.com/jefit-news-product-updates/upcoming-enhancements-revamped-workout-tab-and-improved-exercise-screens/)). Whether editing a routine mid-workout persists to the saved plan: **not found in sources**.
4. **Active workout/logging**: The Workout tab was redesigned for "one-tap" workout start from "My Plans" ([Upcoming Enhancements blog post](https://www.jefit.com/jefit-news-product-updates/upcoming-enhancements-revamped-workout-tab-and-improved-exercise-screens/)). "Pre-Log Set Editing" lets users jump/edit between sets without constraints; 1RM updates dynamically with each set logged, alongside 3-/6-month historical 1RM and percentage tracking (same blog post). Sets can be tagged warm-up/working/drop/failure ([App Store listing](https://apps.apple.com/us/app/jefit-workout-plan-gym-tracker/id449810000)). Plate calculator lets users "edit available weights right from the workout screen," which auto-adjusts planned sets, but it is gated behind JEFIT Elite ([blog post](https://www.jefit.com/blog/best-progressive-overload-apps-for-beginners-in-2026-top-5-reviewed-and-compared); Elite gating per [blog comparison](https://www.jefit.com/blog/best-strength-training-apps-for-2026-7-options-tested-by-lifters)). RPE field and "Load Progression" also sit behind Elite ([same comparison blog](https://www.jefit.com/blog/best-strength-training-apps-for-2026-7-options-tested-by-lifters)). Users can swipe up to collapse the exercise demo video "for focused logging" ([Upcoming Enhancements blog post](https://www.jefit.com/jefit-news-product-updates/upcoming-enhancements-revamped-workout-tab-and-improved-exercise-screens/)).
5. **Rest timer**: Toggle between stopwatch and countdown modes; can apply one rest time to every set at once ([App Store listing](https://apps.apple.com/us/app/jefit-workout-plan-gym-tracker/id449810000)). Accessed/configured via Profile Settings, and the screen "automatically switches to the rest timer after logging" a set ([Upcoming Enhancements blog post](https://www.jefit.com/jefit-news-product-updates/upcoming-enhancements-revamped-workout-tab-and-improved-exercise-screens/)). Lock-screen/notification surfacing: **not found in sources**.
6. **Finish workout**: An "end" button on the exercise-list screen ends the session and shows a summary; a separate mid-workout "session info" view shows training time, actual time, rest time, "wasted time," exercise count, and total weight without ending the session ([JEFIT support: workout summary](https://support.jefit.com/hc/en-us/articles/201540404-How-Do-I-View-My-Workout-Summary-)). Finishing a training *phase* (multi-week block) triggers a confetti animation and options to start the next phase, a bridge week, or a new plan; a BodyMap visualizes trained muscles on the Workout Complete screen (same support article). Discard flow and behaviour on app kill: **not found in sources**.
7. **History & progress**: History tab shows logs, progress photos, notes, and body composition on a color-coded calendar ([JEFIT support: exercise logs](https://support.jefit.com/hc/en-us/articles/202340464-Where-Can-I-See-The-Complete-Logs-For-A-Particular-Exercise-)). Progress tab shows charts for volume, muscle focus, weekly sets per muscle, movement balance, a muscle map, and a "muscle recovery" chart indicating which muscles are ready to train ([App Store listing](https://apps.apple.com/us/app/jefit-workout-plan-gym-tracker/id449810000)). Automatic 1RM per exercise ([App Store listing](https://apps.apple.com/us/app/jefit-workout-plan-gym-tracker/id449810000)).
8. **Delighters/complaints**: Independent review coverage (review, not official) flags a cluttered interface, ads in the free tier, and occasional sync glitches as reasons JEFIT was excluded from at least one "best weightlifting apps" roundup ([Garage Gym Reviews, "Best Weightlifting App"](https://www.garagegymreviews.com/best-weightlifting-app)). A critical third-party review argues JEFIT's 1,300+ exercise library and heavy feature set equate "more" with "better" to its detriment (review, [Dr. Muscle JEFIT review](https://dr-muscle.com/jefit-review-alternative/)). Delighter: JEFIT's own comparison blogs tout the muscle-recovery chart and dynamic 1RM as differentiators — read as marketing, not independent praise ([JEFIT blog](https://www.jefit.com/blog/best-progressive-overload-apps-for-beginners-in-2026-top-5-reviewed-and-compared)).

## Liftin'

1. **Onboarding**: The App Store listing and Liftin's own site do not state a mandatory account/signup; the website advertises redeemable free-trial codes (3 months via website signup vs. 1 month in-app) ([Liftin' website](https://www.liftinapp.co/)). Whether any account at all is required to log a first set: **unverified** (site emphasizes "no account you have to create," per an aggregated feature summary, but this was not confirmed against the App Store listing text itself, so treated as unverified here).
2. **Navigation**: **Not found in sources** beyond platform support (iPhone, iPad, Mac, Apple Watch) ([App Store listing](https://apps.apple.com/us/app/liftin-gym-workout-tracker/id1445041669)).
3. **Program/routine setup**: Built-in full programs including nSuns are available out of the box; users can also build custom weekly programs (day 1–N), program a lift as a percentage of training max, and get automatic progression when thresholds are hit each week; an AI generator can produce a single workout, a routine, or a full program from a text description ([Liftin' website](https://www.liftinapp.co/)). Whether mid-workout edits persist to the template: **not found in sources**.
4. **Active workout/logging**: Warm-up sets, drop sets, rep ranges/AMRAP, RPE tracking, one-rep-max and training-max fields, and notes are all listed features ([Liftin' website](https://www.liftinapp.co/)); a "unified view for tracking reps and RPE/RIR" is described in the same source. Supersets are supported via flexible exercise setup (same source). Previous-performance display and checkbox-style set completion: **not found in sources**. Plate calculator exists and has Apple Watch support (same source).
5. **Rest timer**: A dedicated rest timer view was added for Apple Watch; the iOS Live Activity lets a user mark sets complete and watch the rest timer countdown without unlocking the phone ([Liftin' App Store listing](https://apps.apple.com/us/app/liftin-gym-workout-tracker/id1445041669)). Per-exercise duration and skip/adjust controls: **not found in sources**.
6. **Finish workout**: **Not found in sources** — no summary-sheet or discard-flow details were located in official material.
7. **History & progress**: "Beautiful graphs" for short- and long-term progress, tracking weight, volume, 1RM, training max, or time; CSV-style data export is supported ([Liftin' website](https://www.liftinapp.co/)). A "new heaviest set visualization" highlights PRs ([App Store listing](https://apps.apple.com/us/app/liftin-gym-workout-tracker/id1445041669)). Calendar vs. list view and body measurements: **not found in sources**.
8. **Delighters/complaints**: Apple Health, Activity Rings, and Strava integrations, plus AirPods Pro 3 heart-rate support, are called out as recent additions ([App Store listing](https://apps.apple.com/us/app/liftin-gym-workout-tracker/id1445041669)) — an Apple-ecosystem depth none of the other four apps' official material claims to this degree. Independent Reddit/review complaints specific to Liftin': **not found in sources** (search turned up no citable discussion distinct from unrelated "Lift"-named apps).

## Consensus Patterns

- **Auto-starting rest timer surfaced outside the app** (lock screen / Live Activity / Dynamic Island) is now standard: confirmed for Hevy ([Live Activity page](https://www.hevyapp.com/features/live-activity/)), Strong ([App Store listing](https://apps.apple.com/us/app/strong-workout-tracker-gym-log/id464254577)), Boostcamp ([vs. StrongLifts page](https://www.boostcamp.app/vs/stronglifts)), and Liftin' ([App Store listing](https://apps.apple.com/us/app/liftin-gym-workout-tracker/id1445041669)) — 4 of 5 apps. JEFIT's rest timer exists but lock-screen surfacing wasn't confirmed in sources.
- **Set-type tagging (warm-up / working / drop / failure)** is table stakes: Hevy ([App Store listing](https://apps.apple.com/us/app/hevy-workout-tracker-gym-log/id1458862350)), Strong ([App Store listing](https://apps.apple.com/us/app/strong-workout-tracker-gym-log/id464254577)), Boostcamp ([Features page](https://www.boostcamp.app/features)), JEFIT ([App Store listing](https://apps.apple.com/us/app/jefit-workout-plan-gym-tracker/id449810000)) all confirm it; Liftin' confirms warm-up and drop sets specifically ([website](https://www.liftinapp.co/)).
- **Plate calculators are near-universal**: present in Hevy, Strong, Boostcamp, JEFIT (Elite-gated), and Liftin' — 5 of 5, though JEFIT gates it behind a paywall while the other four ship it free.
- **A template/routine library plus a build-your-own path** exists in all five: none forces users into either pure freeform logging or pure pre-built programs exclusively.
- **Automatic PR detection during/after the workout** is confirmed for Hevy, Boostcamp, and JEFIT (1RM); Strong tracks PRs/1RM in its stats but the "in-session flag" behaviour specifically wasn't confirmed for Strong.

## Divergent Choices

- **Account requirement before logging**: Strong forces signup before use, justified by cross-device sync and sharing ([Strong account article](https://help.strongapp.io/article/143-strong-account)). Liftin' markets itself as not requiring an account at all (unverified against its own App Store text, but consistently described that way in aggregated feature summaries). Trade-off: mandatory accounts enable cloud backup/sharing/social from day one but add onboarding friction; no-account designs are frictionless to start but complicate multi-device sync and social features.
- **Free-tier gating strategy**: Strong caps the *number of custom routines* (3 free) while leaving logging itself unlimited ([App Store listing](https://apps.apple.com/us/app/strong-workout-tracker-gym-log/id464254577)). JEFIT instead gates *specific logging fields* (RPE, plate calculator, Load Progression) behind Elite ([JEFIT comparison blog](https://www.jefit.com/blog/best-strength-training-apps-for-2026-7-options-tested-by-lifters)). Boostcamp keeps RPE/RIR, plate calculator, rest timer, and basic PRs entirely free, gating only advanced analytics (Strength Score, heatmaps) behind Pro ([App Store listing](https://apps.apple.com/us/app/boostcamp-workout-programs/id1529354455)). Trade-off: gating routine *count* preserves full logging fidelity for free users; gating logging *fields* (JEFIT's approach) risks the exact in-workout friction a logging app should minimize, per review criticism of JEFIT's paywalling ([comparison blog](https://www.jefit.com/blog/best-strength-training-apps-for-2026-7-options-tested-by-lifters)).
- **Program breadth vs. curation**: Boostcamp leans on sheer volume — 11,000+ community programs plus 130+ coach-designed ones ([Boostcamp Features page](https://www.boostcamp.app/features)) — while Hevy and Strong keep their built-in libraries comparatively small and treat user-built routines as the primary path (implied by routine-builder-first framing in both apps' own tutorials/help docs). Trade-off: breadth serves users who want a ready-made program matched to a named methodology (5/3/1, PPL); a smaller curated library keeps the browsing experience simpler but pushes more setup work onto the user.
- **Mid-workout template edits**: Strong makes the "does this change persist?" decision explicit and user-facing every time — Update Template / Update Values Only / Keep Original, prompted at finish ([Update Template article](https://help.strongapp.io/article/177-update-template)). Boostcamp's mid-set exercise-swap explicitly "carries weights to substitutes" without describing a template-write-back choice ([Features page](https://www.boostcamp.app/features)). Trade-off: an explicit prompt avoids silently overwriting a program design but adds a modal the user must resolve at exactly the tired, just-finished-lifting moment; silent carry-forward is frictionless but can quietly drift a template's intent.

## Open Decisions for NextSet

1. **Should finishing a workout that deviated from the active program prompt the user to reconcile the template, or should NextSet update it silently (or not at all)?**
   Options: (a) explicit prompt every time (Strong's Update Template / Update Values Only / Keep Original — [help article](https://help.strongapp.io/article/177-update-template)); (b) silent carry-forward with no prompt (Boostcamp's mid-set exercise swap behaviour — [Features page](https://www.boostcamp.app/features)); (c) never write back — treat the logged workout and the saved program as fully separate (not confirmed as any single app's explicit policy in sources, but consistent with NextSet's current `programSync.ts` debounce-to-cloud model per CLAUDE.md).

2. **Should a NextSet account be required before the first logged set, or should logging work fully before any signup?**
   Options: (a) mandatory account up front, justified by cross-device sync/sharing (Strong — [account article](https://help.strongapp.io/article/143-strong-account)); (b) no account required at all (Liftin', per aggregated feature descriptions of its website — [liftinapp.co](https://www.liftinapp.co/)); (c) account required but onboarding is a short goal questionnaire rather than a hard gate (Hevy/Boostcamp/JEFIT pattern — [Hevy App Store listing](https://apps.apple.com/us/app/hevy-workout-tracker-gym-log/id1458862350); [Boostcamp App Store listing](https://apps.apple.com/us/app/boostcamp-workout-programs/id1529354455); [JEFIT App Store listing](https://apps.apple.com/us/app/jefit-workout-plan-gym-tracker/id449810000)). Note: NextSet is already online-only per its own CLAUDE.md, which narrows this to "when" the account gate appears, not "whether."

3. **Which fields get paywalled, if any: routine *count*, logging *fields* (RPE/plate calculator), or only advanced *analytics*?**
   Options: (a) cap the number of saved routines only, leave all logging fields free (Strong — [App Store listing](https://apps.apple.com/us/app/strong-workout-tracker-gym-log/id464254577)); (b) gate specific logging fields like RPE and the plate calculator (JEFIT — [comparison blog](https://www.jefit.com/blog/best-strength-training-apps-for-2026-7-options-tested-by-lifters)); (c) keep all core logging free and gate only higher-order analytics/scores (Boostcamp — [App Store listing](https://apps.apple.com/us/app/boostcamp-workout-programs/id1529354455)).

4. **How should the rest timer surface when the phone is locked or the app is backgrounded?**
   Options: (a) OS-level Live Activity / Dynamic Island + lock screen countdown (Hevy — [Live Activity page](https://www.hevyapp.com/features/live-activity/); Boostcamp — [vs. StrongLifts page](https://www.boostcamp.app/vs/stronglifts); Liftin' — [App Store listing](https://apps.apple.com/us/app/liftin-gym-workout-tracker/id1445041669)); (b) local push notification only (not confirmed as any app's exclusive approach in sources — flagged here as a real third option, not attributed); (c) in-app banner only, no OS-level surfacing (JEFIT's confirmed behaviour is app-internal auto-switch-to-timer-screen, with no lock-screen surfacing found in sources — [Upcoming Enhancements blog post](https://www.jefit.com/jefit-news-product-updates/upcoming-enhancements-revamped-workout-tab-and-improved-exercise-screens/)).

5. **Should exercise-library breadth or program-library breadth be the differentiator, or should NextSet stay deliberately narrow?**
   Options: (a) very large exercise/program library as the selling point (JEFIT's 1,400+ exercises and Boostcamp's 11,000+ programs — [JEFIT App Store listing](https://apps.apple.com/us/app/jefit-workout-plan-gym-tracker/id449810000); [Boostcamp Features page](https://www.boostcamp.app/features)); (b) a small curated library with user-built routines as the primary path (Hevy/Strong's comparatively smaller built-in libraries, per their own tutorials/help docs). Note a review explicitly argues breadth-for-its-own-sake is a liability, not a strength, for JEFIT specifically ([Dr. Muscle review](https://dr-muscle.com/jefit-review-alternative/)) — this is a citable counter-argument to "more is better," not a recommendation either way.

6. **Should NextSet show previous-session performance inline on the active set row, and if so, where?**
   Options: (a) previous performance shown to the left of/alongside the current set input as a constant reference (Hevy — [Help Centre feature guide](https://help.hevyapp.com/hc/en-us/articles/33106320824727-Everything-You-Need-to-Know-About-the-Hevy-App-2025-Features-Guide)); (b) auto-fill the weight/reps fields from last session rather than just displaying them (claimed for Strong only in a third-party review, not Strong's own docs — [RepReturn review](https://repreturn.com/strong-app-review/), flagged as unverified against official sources); (c) no persistent previous-performance display at all (not confirmed as any app's choice in sources — included as the null option).

7. **Should a multi-week program's completion (a full mesocycle/phase, not just one workout) get its own distinct celebratory/summary moment?**
   Options: (a) yes — a phase-completion screen distinct from the per-workout summary, with a specific next-step choice (JEFIT's confetti + BodyMap + "start next phase / bridge week / new plan" — [JEFIT support: workout summary](https://support.jefit.com/hc/en-us/articles/201540404-How-Do-I-View-My-Workout-Summary-)); (b) no distinct phase-level moment — every workout's finish screen looks the same regardless of where it falls in a program (not explicitly confirmed as any other app's choice, but implied by the absence of any phase-completion feature in Hevy's, Strong's, Boostcamp's, or Liftin's sourced material).
